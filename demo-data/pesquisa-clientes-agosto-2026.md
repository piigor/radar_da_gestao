# Pesquisa de Clientes, Agosto 2026

> Documento totalmente fictício para demonstração.

**Amostra:** 420 respostas, coletadas entre 01/08/2026 e 31/08/2026.

| Tema | Resultado |
|---|---:|
| Encontrou o produto desejado | 78% |
| Considerou o preço adequado | 71% |
| Recomendaria a VivaCasa | 74% |
| Relatou produto indisponível | 19% |
| Considerou a retirada em loja conveniente | 83% |
| Avaliou positivamente a organização das lojas | 81% |

## Comentários recorrentes

- Clientes valorizam a possibilidade de retirar pedidos em loja.
- Clientes relatam dificuldade para saber se o produto está disponível antes da visita.
- Clientes elogiam a curadoria visual e a variedade de organização.
- Clientes pedem mais clareza sobre prazo de entrega.

## Limitações

A pesquisa não é probabilística e não representa necessariamente toda a base de clientes. Os resultados são sinais para investigação, não prova causal.
